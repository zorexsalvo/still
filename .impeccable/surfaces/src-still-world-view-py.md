# Read-only World overview

Mode: Read. The user requested a UI for the existing world. Keep the current JSON API and inherit the shipped diary system rather than introduce a new visual identity.

## Direction contract

THESIS: Show the facts behind the diary without offering controls over the life. No metric-card dashboard or decorative terminal costume.

OWN-WORLD: Existing cool ground, dark ink, blue underlined links, sans date/data apparatus. Monospace is reserved for literal personal-file contents.

STORY: The reader can locate the courier, inspect deliveries and the private project, understand who belongs where, and distinguish a quiet world from a missing worker check-in. Backdated activity is explicit.

FIRST VIEWPORT: Shared Still masthead, UTC as-of time, Diary/World navigation, then the courier's location, carried item, next tick and check-in. Personal file, places, delivery table and recent changes follow in one document column.

FORM: Extension of the established reading surface, inheriting seed:b310af4a7baddb8f. Standard lists, definition lists and a keyboard-scrollable table; no new concept roll or physical-material simulation. The visitor's interactions are navigation and inspection only.
