# Still artwork

- **`still-cover.png`** — ready-to-publish blog cover, **1200 × 630 px**.
- **`still-cover.svg`** — editable source. Uses the site's Georgia/serif typography; use the PNG for a consistent published appearance on machines without Georgia.
- **`../../src/still/static/favicon.svg`** — scalable satchel mark.
- **`../../src/still/static/favicon.ico`** — browser fallback containing native-alpha 16, 32 and 48 px representations.

Suggested cover alt text: “Still: a courier with a messenger bag and a raised hand greets the repair shop. A courier’s diary, written locally by Gemma.”

These are original vector assets derived from Still's established palette and courier illustration, not stock art or model-generated images. The scene is illustrative, not a screenshot or record of a live event. No font files are bundled.

The PNG is a direct Chromium raster export of the SVG. Its embedded provenance records the relative source path and SVG SHA-256. Each PNG inside the ICO likewise carries the favicon source and export-size provenance. Re-export the cover at 1200 × 630 and preserve/update that provenance if editing it.

The favicon is linked by the shared page frame; the blog cover is intentionally outside the application package. No diary data or worker changes are needed to use these assets.
